My Journey to Become a Web Developer

My First Blog

Welcome to my blog! I am currently learning Web Development at SMIT Peshawar with Sir Abdul Musavir. Every new topic helps me improve my skills and brings me closer to becoming a professional web developer. I started with HTML, where I learned how to create the structure of a webpage using headings, paragraphs, images, links, lists etc. Now I am learning CSS, which allows me to design beautiful and responsive websites by adding colors, fonts, spacing, and layouts. My goal is to build modern websites and useful web applications that solve real-world problems. I believe that learning, practicing, and staying consistent are the keys to success. This journey has just begun, and I am excited to continue improving my skills every day and continue reading
